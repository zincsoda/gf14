The app combines four public references. Each one supplies a different part of the component catalog or character decomposition tool.

01 Primary standard

GF 0014-2009

Specification of Common Modern Chinese Character Components and Component Names

The Chinese language standard defines the component inventory used by this app, including component IDs, source names, and pinyin.

Used for: the 514-component catalog and its identifying details.

View the document archive
02 Structured data

hanzi-chai

This dataset provides machine-readable GF0014 records, character decomposition models, and mappings for components represented by Unicode or private-use characters.

Used for: decomposition results, component mappings, and generated glyph strokes.

View the package
03 Character set

General Standard Chinese Character Table

Level 1 of China's official character table contains the 3,500 commonly used characters covered by the decomposition lookup.

Used for: deciding which characters are included in the lookup set.

View the official table
04 Character metadata

Unicode Unihan Database

Unihan collects standardized properties for Han characters, including Mandarin readings and English definitions.

Used for: filling searchable readings and definitions where available.

Read about Unihan

How it fits together

From references to the app

  1. GF 0014-2009 supplies the component system.
  2. hanzi-chai turns that system and character decompositions into structured data.
  3. The Level 1 character table sets the 3,500-character scope.
  4. Unihan adds readings and English definitions used by search and display.
